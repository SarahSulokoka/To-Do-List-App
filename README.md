# To-Do-List-App

A simple and interactive to-do list application built using HTML, CSS, and JavaScript. 
Users can add tasks, mark them as completed, and delete them. The tasks are saved in the browser's localStorage, ensuring persistence even after page reloads.

## Features

- Add tasks to your to-do list
- Mark tasks as completed or incomplete by clicking on them
- Delete tasks from the list
- Data persists across page reloads using `localStorage`
